# Résultats

Ce dossier contient uniquement les artefacts légers destinés au rapport : figures, tableaux CSV agrégés et exemples visuels. Les sorties brutes sont écrites dans `results/runs/` et ignorées par Git.

Ne publiez pas de chiffres avant d’avoir exécuté `configs/benchmark_full.json` sur le même GPU et vérifié le manifeste SHA-256. Le projet ne fournit aucun résultat inventé.
